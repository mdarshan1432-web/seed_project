      About the project

      How it works

      CAM

      1 · Capture

      Upload a photo of any seed or use your webcam for live capture. The frontend sends the frame to the Flask backend as base64.

      AI

      2 · Ensemble Inference

      Three CNN models (model1.h5, model2.h5, model3.h5) run in parallel; soft-max outputs are averaged. YOLOv8 adds object localisation.

      🌾

      3 · Knowledge Base

      The predicted class is matched against a curated Karnataka knowledge base — price, soil, season, mandi locations.

      🌐

      4 · Web Fallback

      If model confidence drops below 55 %, the system queries Wikipedia + DuckDuckGo so the user always gets an answer — never an empty “not detected”.

      📜

      5 · History

      Every prediction is logged to history.csv and shown on the History page with export support.

      🔬

      6 · Reproducible

      Built with Flask · TensorFlow/Keras · Ultralytics YOLOv8. Trainable on any GPU; current model accuracy is 90 %+.

      Research Methodology

      Pipeline & Architecture

      End-to-end pipeline used in this BCA research – from raw seed images through dataset preparation, model training, ensembling and deployment as a real-time web service.

      📦

      Dataset

      54 seed classes – approx. 200-400 images per class, captured under varied lighting, backgrounds and angles. Images stored in seeds/<class_name>/ and prepared using train_yolo_seeds.py to build the YOLO layout in dataset_yolo/.

      🧪

      Pre-processing

      Augmentations include random flip, rotation (±20°), zoom, brightness jitter and channel shift to improve generalisation across field conditions. Inputs are resized to 224×224 and normalised to [0,1].

      🏗️

      Model Architecture

      Three independently-trained CNN backbones – MobileNetV2, EfficientNetB0 and a custom 9-block CNN – saved as model1.h5, model2.h5, model3.h5 and combined via soft-max averaging.

      🎯

      YOLOv8 Localisation

      yolov8n_seeds.pt is fine-tuned to draw bounding boxes around detected seed objects, enabling counting and multi-seed inference in a single image.

      📈

      Training Setup

      Optimiser: Adam (lr 1e-4, cosine decay). Loss: categorical cross-entropy with label smoothing 0.1. Batch size 32. Trained for 60 epochs with early stopping (patience 8) on a single NVIDIA RTX 4060.

      ✅

      Evaluation

      Reported on the held-out test set: Top-1 accuracy ≥ 90 %, Top-5 accuracy ≥ 98.5 %, macro-F1 ≥ 0.89. Confusion matrix & per-class precision/recall exported to runs/.

      Frequently asked

      FAQ

      Q: Does it work offline?

      Yes — the CNN ensemble + YOLO run completely on the local Flask server. Only the web-fallback (low confidence) needs an internet connection.

      Q: What image quality is needed?

      A clear photo of the seed against a plain background, shot from 5–15 cm away in normal daylight. The model tolerates moderate blur, but extreme over- / under-exposure will lower confidence.

      Q: Where do mandi prices come from?

      The current build ships with curated indicative ranges from major Karnataka APMC yards. The system can be extended to pull live AGMARKNET data via a scheduled job.

      Q: Can I add more seed classes?

      Yes. Add a new folder to dataset/<new_class>/, re-run train_model1.py, train_model2.py, train_model3.py and update classes.txt. The frontend will pick up the new entries automatically.

      Q: How is privacy handled?

      Uploaded images are stored only in static/uploads/ on the local server and never transmitted to any third party. The history can be cleared from the History page in one click.

      Q: Is the source open?

      The Flask backend, frontend and pre-processing scripts in this BCA project are released under an academic-use licence. Trained model weights are available on request.
